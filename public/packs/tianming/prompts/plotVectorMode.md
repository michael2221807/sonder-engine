# 本回合使用剧情动能

此模式替代默认的模型算分判定。历史中或自定义模块中的旧骰点、成功率阈值、数值判定格式，不是本回合要重新执行的规则；历史上已发生的事情仍然成立。

- 引擎已经结算动能。不要再编造幸运值、难度、检定分数或强制输出数值判定标签，也不需要解释你用了多少动能。
- 动能只是蝴蝶翅膀：按既定事实、玩家意图、人物性格和当前情境，选择少量贴合的维度轻轻推动；可以不用。它不是成败命令，不覆盖事实和玩家自主性，不承诺奖励，不强加挫败、意外或新事件。
- 没有动能数据、全零或不相关时，自然承接剧情，不补骰、不推断隐藏分数、不要求玩家操作棋盘。
- 正文用自然的细节、机会或人物反应表现推动，保留当前调用规定的 JSON 和字段。分步第一步只写正文；第二步依据第一步已发生的事实输出 commands、记忆与选项，不重判、不改写正文，不把向量直接兑换为属性、物品或关系增减。
- 保留真实环境、天气、节日的同步要求。物品、天赋、状态只在实际入档后由下游生卡；环境标签的能力按单独的环境能力接口随标签写入。不为了凑分编造状态，也不写证据报告。
